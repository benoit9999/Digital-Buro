Réparer ou remplacer ? Notre avis honnête.

Nous préférons vous faire économiser une réparation inutile que vous vendre une pièce qui ne sauvera pas votre machine. Voici comment nous raisonnons.

{{ ui.icon('wrench') }}

La réparation vaut presque toujours la peine si…

  • {{ ui.icon('check') }}votre imprimante est un modèle laser ou professionnel, conçu pour durer ;
  • {{ ui.icon('check') }}la panne touche une pièce d’usure : rouleaux, tambour, unité de fusion ;
  • {{ ui.icon('check') }}vous avez encore des cartouches ou des toners pour ce modèle ;
  • {{ ui.icon('check') }}la machine est installée dans votre réseau et utilisée par toute l’équipe.
{{ ui.icon('refresh') }}

Un remplacement peut être plus sensé si…

  • {{ ui.icon('check') }}il s’agit d’une petite jet d’encre d’entrée de gamme dont la tête est hors d’usage ;
  • {{ ui.icon('check') }}les pièces ne sont plus disponibles pour ce modèle ;
  • {{ ui.icon('check') }}le coût de la réparation approche celui d’une machine neuve équivalente.

Dans ce cas, nous vous le disons et nous vous conseillons une machine adaptée à votre usage réel. Voir la vente de matériel.
